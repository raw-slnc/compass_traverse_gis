about=Compass Traverse GIS is a QGIS plugin for simple compass-survey workflows. It supports survey note entry, CSV or Excel import, traverse computation, point/line/polygon generation, and initial survey deliverables inside QGIS. It can also be used as a practical learning tool for understanding how field observations connect to traverse computation and GIS data creation. Table import requires the pandas package (and openpyxl for Excel files).
